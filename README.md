# Tamil Nadu Crop Yield Analyser 🌾

A data analysis project exploring crop production trends across Tamil Nadu districts using Python, Pandas, SQL, and Matplotlib.

## About
This project analyses Tamil Nadu agricultural data to uncover insights about crop production patterns, district-wise performance, seasonal trends, and year-over-year growth.

## Tech Stack
- **Python** — core programming
- **Pandas** — data loading and cleaning
- **SQLite** — database storage and SQL queries
- **Matplotlib** — data visualizations

## Key Insights
- Top 10 crops by total production in Tamil Nadu
- Most productive districts
- Year-wise production trends
- Season-wise crop distribution
- Most cultivated crops by area

## How to Run
```bash
pip install pandas matplotlib
python analysis.py
```

## Dataset
Tamil Nadu Crop Production dataset from Kaggle containing district-wise, season-wise crop production data from 2001–2014.
